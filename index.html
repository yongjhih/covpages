Why Choose Covpages?

Eliminate external SaaS subscriptions, privacy leaks, and slow CI steps with a native GitHub Pages workflow.

📦 97.6% Git Delta Compression

Covpages normalizes line endings and sorts LCOV records deterministically. 100 historical commits compress into just 1.24 MB in Git packfiles.

🏷️ Scoped SVG Badges with 1-Click Copy

Generate coverage badges not just for your repo, but for every branch, subfolder, and file. Click to copy markdown directly into your README.

🎨 GitHub-Identical UI & Syntax Highlighting

Identical tree/blob routing, keyboard shortcuts (t, n, ESC), line numbers, hit gutters, and Prism.js syntax highlighting for all major languages.

📈 Multi-Commit Trends by Folder & File

Track coverage fluctuations across commits. Inspect trendlines by repository, individual directory, or specific source file.

🧩 +React & Component Reusability

Import <Covpages /> directly into React, Next.js, and Docusaurus documentation sites, or embed as a standard <cov-pages> Web Component.

⚡ Zero-Server 1-Click GitHub Actions

Run npx covpages init to generate a zero-config GitHub Actions workflow that automatically publishes to GitHub Pages on every push.

Interactive Badge Generator

Embed live SVG coverage badges into your README.md for your entire project or specific folders.

Quickstart & Setup

Get up and running in under 5 minutes with zero configuration.

# 1. Initialize GitHub Actions Workflow in your repository npx covpages init # 2. Push to GitHub! git add .github/workflows/covpages.yml git commit -m "ci: add covpages coverage report workflow" git push origin main # Your coverage will be automatically published to https://<owner>.github.io/<repo>/
# vitest.config.ts export default { test: { coverage: { provider: 'v8', reporter: ['text', 'lcov'], }, }, }; # Run tests and generate covpages npx vitest run --coverage npx covpages generate --input coverage/lcov.info --output docs/covpages
# Run Flutter test coverage flutter test --coverage # Generate Covpages report from coverage/lcov.info npx covpages generate --input coverage/lcov.info --output docs/covpages
# Run Go tests with coverage profile go test -coverprofile=coverage.out ./... # Convert or use covpages parser npx covpages generate --input coverage.out --output docs/covpages
# Run pytest with lcov output pytest --cov=src --cov-report=lcov:coverage/lcov.info # Generate Covpages report npx covpages generate --input coverage/lcov.info --output docs/covpages
# Install cargo-llvm-cov cargo install cargo-llvm-cov # Run tests and generate lcov cargo llvm-cov --lcov --output-path coverage/lcov.info # Generate Covpages report npx covpages generate --input coverage/lcov.info --output docs/covpages

Reusable Component Architecture & React Integration

Easily integrate Covpages into React applications, Next.js, and Docusaurus portals.

import React, { useState, useEffect } from 'react'; import { Covpages } from 'covpages/react'; import 'covpages/style.css'; export function CoveragePortal() { const [data, setData] = useState(null); useEffect(() => { fetch('/covpages-data.json') .then(res => res.json()) .then(setData); }, []); if (!data) return <div>Loading coverage report...</div>; return ( <div style={{ height: '100vh', width: '100%' }}> <Covpages data={data} theme="auto" initialTab="files" /> </div> ); }
